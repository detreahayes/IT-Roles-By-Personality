# IT-Roles-By-Personality
A simple web application that helps users explore IT career paths based on personality traits. This project is currently in its early stages and uses a single index.html file as the foundation for future development.


🌟 Project Purpose
## Project Purpose
Many people enter tech without knowing which roles align with their natural strengths. This app aims to make that journey easier by providing personality‑based role suggestions in a clean, interactive format.
